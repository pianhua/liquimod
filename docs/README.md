# LiquiMod 文档索引

这里保存需要长期维护、能够帮助用户或接手者复现现状的正式文档。临时聊天结论、一次性截图和本机调试脚本不应直接放入这里。

## 当前入口

- [项目 README](../README.md)：用户安装、功能边界、源码构建和质量门禁。
- [AGENTS.md](../AGENTS.md)：Agent 与开发者协作、分支、验证和发布守则。
- [HANDOVER.md](../HANDOVER.md)：当前 v0.6.1 交接状态和已知边界。
- [DECISIONS.md](../DECISIONS.md)：已经确认或暂缓的产品决策。
- [CONTRIBUTING.md](../CONTRIBUTING.md)：面向贡献者的简化开发流程。

## 主题文档

- [版本历史](releases.md)：从早期 tag 到 v0.6.1 的可追溯版本索引。
- [XXMI 注入与便携化踩坑记录](XXMI-注入与便携化踩坑记录.md)：管理员权限、Hook 注入、拖放限制和便携目录的实测结论。
- [仓库维护与磁盘清理](development/repository-maintenance.md)：目录职责、构建产物、归档和清理边界。

## 文档维护规则

1. 影响用户行为、数据安全、游戏运行态或发布流程的决定，先更新 `DECISIONS.md`，再实现。
2. 每个正式版本必须有 Release、tag 和对应的变更说明；不能只依赖 GitHub 自动生成摘要。
3. 排障文档只记录已经验证的现象、根因、修复和未覆盖项；推测必须明确标注。
4. 临时截图、CDP 探针、真实 Mod 包和本机运行数据保留在被忽略的本地目录或 E 盘归档，不提交到仓库。
