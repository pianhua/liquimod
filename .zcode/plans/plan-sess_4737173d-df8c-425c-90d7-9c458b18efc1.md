## LiquiMod 崩铁单游戏重构：侧边栏 6 分类 + 分类安装 + 筛选 + 设置页大改

**方向（主人已全部拍板）：** 集中崩铁；侧边栏固定 6 类「角色/光锥/立绘/场景/NPC/其他」从上到下平铺、空类也显示；去掉「全部 Mod」；主页=角色网格；筛选=搜索+启用态；**分类不读用户 Mods 目录**（那是 3Dmigoto 自由部署区），由 LiquiMod 自身管理；安装时手动分类（全局界面弹窗选大类+角色，进入具体对象详情界面默认装到该对象）；其它区卡片照抄角色现有卡片样式、暂不加立绘。

### 核心数据模型（关键设计）

**仓库结构不变**（`mods/<character>/<mod>`），但 `character` 字段语义扩展——既可以是角色名，也可能是大类标识。**分类由 character 单一推导 category_id，一处维护（扫描/安装都走同一函数），杜绝两处不一致。**

| character 值 | 归类 | category_id |
|---|---|---|
| 81 个 HSR 角色名之一 | 角色（虚拟类） | NULL |
| `npc` | NPC | → categories 表的 NPC |
| `lightcone` | 光锥 | → 光锥 |
| `portrait` | 立绘 | → 立绘 |
| `scene` | 场景 | → 场景 |
| `other` 或其他未知名 | 其他 | → 其他 |

（categories 表预置 光锥/立绘/场景/NPC/其他 五条 + 角色为虚拟类；现有用户自定义分类数据保留不删，前端不再展示，存量归入——见下。）

### 一、后端（Rust）

**1. db.rs**
- `ensure_default_categories()`：INSERT OR IGNORE 预置五条固定分类（ord 1-5），与用户自定义重名时不覆盖
- 新 `resolve_category_id(character)` 概念下沉到 commands（app 层），由 HSR 角色表 + character 值映射

**2. commands.rs（app）**
- `character_to_category_id(hsr, db, character) -> Option<i64>`：已知角色→NULL；npc/lightcone/portrait/scene→对应预置分类；其它→「其他」分类
- `install_mod` 改：新增 `category` 值（前端传大类）→ 内部映射到 character 存储（角色→角色名；非角色→大类标识）
- scan 归类：`list_mods` 读出后对 category_id 为 NULL 且 character 非已知角色的，映射到「其他」（幂等，不为已有 category_id 覆盖）
- `list_category_mods(category_id)` 按 category_id 查（现有已支持）；「角色」还是走 character 虚拟类查询

**3. 迁移**：存量「未分类」（category_id NULL + 未知角色）→ 归「其他」；存量自定义分类的 mod 保留 category_id（前端不展示自定义分类，其 mod 会藏在数据里——计划内置一次 `migrate_legacy_categories` 把自定义分类 mod 转 NULL → 归其他，保持可见，不丢数据可恢复）

### 二、前端（Svelte）

**4. view.ts**：`View = {kind:"home"}（角色） | {kind:"type"; id; name}（五实体类）`；删 all/uncat/category/character；viewKey 同步

**5. Sidebar.svelte**：固定 6 项（「角色」=home 且用 config.character_category_name + 五条实体类带计数，空也显示）；去掉「全部 Mod」「未分类」；底部预设保留；**新建自定义分类入口移除或折叠**（自定义分类功能本次不展示，见说明）

**6. +page.svelte**：home→CharacterGrid；type 视图→ModCardGrid（list_category_mods）；sort 逻辑适配；安装入口带当前上下文

**7. 安装分类（InstallOverlay.svelte + install.svelte.ts）**
- 全局视图（角色网格 home）拖入 → 弹窗「选大类：角色/光锥/立绘/场景/NPC/其他」，选角色→再选具体角色
- 已在某实体类列表页、或角色详情页拖入 → **默认装到当前对象/类**（不弹）
- 后端 install_mod 接收类别

**8. 启用态筛选**：ModCardGrid 加 `enabledFilter: all|on|off` 分段（全部/已启用/未启用），与 query 组合（view.ts filterMods 扩展）

**9. 其它区卡片**：复用现有 **ModCard**（大卡片带缩略图；无缩略图时首字母占位）——即角色区那套,保持全站统一,非角色区不强加立绘

**10. Settings.svelte 布局大改**：区块式重排为 外观→启动→目录→解压密码本→行为→日志→关于（新增 About 区块：版本+说明）。纯结构/视觉重排，字段与命令不变。
